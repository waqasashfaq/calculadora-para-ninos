# Calculadora para Niños

Calculadora con botones grandes y un juego de práctica para que los niños de primaria aprendan sumas, restas y tablas de multiplicar jugando.

## Qué incluye
- Calculadora fácil de usar, pensada para niños
- Juego de práctica con sumas, restas y tablas
- Ejemplo de resta llevando explicado paso a paso
- Consejos para padres y maestros

## Más ejercicios
Los niños pueden practicar operaciones con explicaciones completas en [la-calculadoraalicia.com](https://la-calculadoraalicia.com/), una herramienta educativa gratuita que muestra cada paso como en la pizarra.
